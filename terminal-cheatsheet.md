Angular CLI – ng Befehle

Kurzform Langform Funktion
ng new poll-app ng new poll-app Neues Angular-Projekt erstellen
ng s -o ng serve --open Entwicklungsserver starten + Browser öffnen
ng g c header ng generate component header Komponente erstellen
ng g s data ng generate service data Service erstellen
ng g i user ng generate interface user Interface erstellen
ng g p filter ng generate pipe filter Pipe erstellen
ng g d highlight ng generate directive highlight Directive erstellen
ng b ng build Projekt bauen
ng v ng version Angular-Version anzeigen
ng test ng test Tests ausführen

PowerShell – Dateien und Ordner

cd .. # Eine Ebene zurück
cd src/app # In einen Unterordner wechseln
cd ~ # Zum Benutzerverzeichnis
pwd # Aktuellen Pfad anzeigen
ls # Verzeichnisinhalt anzeigen
ls -Force # Auch versteckte Dateien anzeigen
code . # Aktuellen Ordner in VS Code öffnen
code .prettierrc # Bestimmte Datei in VS Code öffnen
cls # Terminal leeren
